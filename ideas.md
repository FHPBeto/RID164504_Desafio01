# Brainstorming de Design - Análise de Modelo de Banco de Dados

## Contexto
O projeto é um site interativo para apresentar a análise de um modelo de banco de dados de uma biblioteca universitária. O público-alvo são estudantes ou profissionais de TI que precisam entender modelagem de dados. O conteúdo é técnico, mas precisa ser apresentado de forma didática e visualmente atraente.

  **Core Principles**: Clareza estrutural, contrastes fortes, honestidade dos materiais (dados), funcionalidade crua mas refinada.
  **Color Philosophy**: Fundo off-white (papel antigo) com acentos em azul cobalto (caneta) e vermelho alerta (correções). Evoca a sensação de correção de provas e anotações técnicas.

  **Signature Elements**: Caixas de texto com bordas pretas grossas, tipografia monoespaçada para dados técnicos, ícones de "check" e "x" estilizados como carimbos.
  **Interaction Philosophy**: Feedback tátil e imediato. Hover revela detalhes técnicos como se estivesse usando uma lupa.
  **Animation**: Transições secas e rápidas (step-timing), evocando a virada de páginas ou carimbos batendo no papel.
  **Typography System**: Títulos em **Space Grotesk** (geométrica, técnica) e corpo em **JetBrains Mono** (código, dados).

## Escolha Final

Vou seguir com a abordagem **Neobrutalismo Acadêmico**.

**Justificativa**: Este estilo se encaixa perfeitamente no contexto de "análise e correção". A estética de "papel e caneta", bordas grossas e cores de destaque (azul/vermelho) reforça a ideia de um documento técnico sendo revisado. Além disso, o uso de tipografia monoespaçada para os dados do banco traz a tecnicidade necessária, enquanto o visual "brutalista" garante que a informação seja o foco principal, sem distrações desnecessárias de efeitos complexos. É didático, memorável e funcional.
